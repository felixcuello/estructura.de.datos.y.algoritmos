# Estructura de Datos y Algoritmos | UP

## Introducción

En este repositorio encontrarán materiales y recursos relacionados con la materia de Estructura de Datos y Algoritmos
impartida en la Universidad de Palermo (UP). El objetivo es proporcionar a los estudiantes herramientas y ejemplos
prácticos para comprender mejor los conceptos fundamentales de la materia.

En este repositorio se incluyen:

- **CP Server**: Un servidor de Competitive Programming para practicar problemas de algoritmos y estructuras de datos.
- **Pizarrones Digitales**: Capturas y notas de las clases dictadas en la universidad.
- **Códigos de Ejemplo**: Implementaciones en C de los algoritmos y estructuras de datos discutidos en clase.
- **Recursos Adicionales**: Algunos PDFs y enlaces a materiales complementarios para profundizar en los temas tratados.

## Estructura del Repositorio

- [pizarrones/](pizarrones/): Carpeta con las imágenes y notas de los pizarrones digitales.
- [codigo/](codigo/): Carpeta con los códigos de ejemplo en C.
- [recursos/](recursos/): Carpeta con PDFs y otros materiales adicionales.

## CP Server

El CP server es un servidor dedicado a la práctica de problemas de programación competitiva. Está configurado para que
los estudiantes puedan resolver problemas, enviar sus soluciones y recibir _feedback_ de manera inmediata.

La idea es tener problemas para practicar los problemas vistos en clase y otros adicionales para mejorar las habilidades
de resolución de problemas.
